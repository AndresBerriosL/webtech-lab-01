## Funcionalidades interactivas

- **Cursos:** en la sección "Cursos" se pueden buscar cursos escribiendo en el campo de búsqueda, agregar nuevos cursos mediante el formulario y eliminarlos con su botón correspondiente.

- **Formulario de contacto:** en la sección "Contacto", al enviar datos inválidos se muestran mensajes junto a cada campo y, cuando los datos son correctos, aparece una confirmación.

- **Cambio de tema:** el botón "Cambiar tema" ubicado en la cabecera permite alternar entre el tema claro y oscuro.
